Практическая работа 4

Программа позволяет создавать и просматривать заметки

Обычное нажатие открывает полный текст заметки
Двойное нажатие делает заметку важной, появляется звезда и меняется цвет карточки
Долгое нажатие открывает редактирование, после сохранения текст обновляется
Свайп влево удаляет заметку
Свайп вправо убирает отметку важности
Удаление можно отменить кнопкой внизу экрана

Заметки хранятся до закрытия программы
